# 동백꽃 — Flow AI 편집본 v1.1

사용자 수정 반영: 어머니는 전부 화면 밖 음성. 닭싸움에 어머니가 등장하지 않는다. 최초 시나리오 파일은 이력으로 보존한다. 현재 제작은 이 편집본과 data.js를 기준으로 한다.

10씬·35컷·총 240초. Flow의 8초 생성 기준으로 35개 영상(총 생성 280초)을 만들고 앞 4~8초를 사용하여 240초로 편집한다. 선택 모델의 지원 길이는 Flow에서 확인한다. 한국어 음성이 불명확하면 별도 음성으로 편집한다. 각 컷의 첫 프레임은 해당 컷 번호 PNG이며 후속 행동 이전의 자세다. 영상은 아직 생성하지 않았다.
